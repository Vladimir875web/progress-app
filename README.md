# PROGRESS — журнал тренировок + тренер

Приложение: выбор роли (тренер / клиент), журнал тренировок, показатели, редактируемая программа.

## Структура проекта

```
progress-app/
├── index.html          — главная страница
├── package.json        — зависимости
├── vite.config.js      — настройки Vite
├── vercel.json         — деплой на Vercel
├── public/
│   └── favicon.svg
└── src/
    ├── main.jsx        — точка входа
    ├── index.css       — глобальные стили (фон, мобильная вёрстка)
    └── App.jsx         — всё приложение (≈1200 строк)
```

## Запуск на компьютере

1. Установи Node.js: https://nodejs.org
2. Открой терминал в этой папке:
   ```
   npm install
   npm run dev
   ```
3. Открой в браузере: http://localhost:5173

## Как продолжить с телефона

### Вариант 1 — Редактировать код (Cursor / GitHub)

1. Скопируй папку `progress-app` в Google Drive / OneDrive / iCloud
2. На телефоне открой через **Cursor** (если есть) или **GitHub** + веб-редактор
3. Главный файл для правок: `src/App.jsx`

### Вариант 2 — Опубликовать в интернет (Vercel, бесплатно)

1. Зарегистрируйся на https://vercel.com
2. Загрузи папку `progress-app` (или подключи GitHub)
3. Vercel сам соберёт проект — получишь ссылку типа `https://твоё-имя.vercel.app`
4. Открывай приложение в браузере телефона — данные сохраняются локально

### Вариант 3 — Использовать как PWA

После деплоя на Vercel: в Chrome/Safari на телефоне → «Добавить на главный экран».

## Что уже работает

- Выбор: **Тренер** или **Клиент**
- **Клиент**: тренировки, показатели, программа (редактируемая), профиль
- **Тренер**: клиенты, программы, просмотр прогресса
- Данные в `localStorage` (на телефоне — в браузере)
- Экспорт / импорт JSON (кнопки в шапке клиента)
